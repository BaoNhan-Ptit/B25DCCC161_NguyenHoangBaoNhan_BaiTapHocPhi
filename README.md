## Cách chạy

Cài JDK 8 trở lên. Từ thư mục gốc của repository, mở terminal và chạy từng câu trong thư mục tương ứng. Ví dụ với Câu 1:

```sh
cd Cau1
javac -encoding UTF-8 Main.java
java Main
```

Dán dữ liệu mẫu hoặc nhập dữ liệu theo định dạng trong đề. Chương trình đọc từ bàn phím và in kết quả ra terminal. Để chạy câu khác, quay lại thư mục gốc bằng `cd ..` rồi dùng thư mục `Cau2`, `Cau3` hoặc `Cau4`.
